## Independent D-22 native owner-burst failure

The accepted `netns-density-295` D-22 in-guest lane is the Tier-3 half of R5-28/R5-31 (`feature-delta.md:644-676`). R5-31 requires no guest connection of an aborted flow to remain open one second after abort, with an outcome asserted **for every flow**; the 1,000-flow abort-to-reset p50/p99 values are reported but not asserted (`feature-delta.md:13062`). The source-local burst cell separately enforces the one-second owner-state bound before it can read every C reset and report latency (`crates/overdrive-init/src/guest_flow/real_kernel.rs:1416-1418,1900-1963`). This is an existing native gate, not a new D13 scenario.
