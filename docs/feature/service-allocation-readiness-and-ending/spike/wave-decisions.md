# Spike wave decisions: service-allocation-readiness-and-ending

**V-number mapping (findings files to the feature delta).** The findings files carry earlier
numbers. `findings-listen-hooks.md` "V32/V34, V33/V35, V35/V37, V37/V39" reads old/new: old V32 =
V34, old V33 = V35, old V35 = V37, old V37 = V39. `findings-guest-signal.md`: old V34 = V36, old V36
= V38. `findings-boot-cost.md` is V41. The "50 to 80 ms" figures in `findings-guest-signal.md` are
superseded by `findings-boot-cost.md` (+0.36 ms at p50 for the listen additions).
