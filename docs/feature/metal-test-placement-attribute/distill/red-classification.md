## Notes for DELIVER

- The conformance driver has been compiled, linted and run only as far as `OwnerCore::new()` (the scaffold). A scenario that fails for an environment reason (not a behaviour reason) returns to DISTILL, not to the crafter.
- Five `.stderr` snapshots under `crates/overdrive-testing/tests/compile_fail/` were written from the spike's recorded rustc output, not generated; see `test-scenarios.md` section D for which lines are contract.
